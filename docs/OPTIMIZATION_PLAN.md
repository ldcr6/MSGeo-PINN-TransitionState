## 📊 评分计算器

### RMSD评分（40分）
```python
if RMSD <= 0.2:
    score = 40.0
elif RMSD >= 0.5:
    score = 0.0
else:
    score = 40 - ((RMSD - 0.2) / 0.3) * 40
```
