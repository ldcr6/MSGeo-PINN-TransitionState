## 🔧 技术特点

### 模型架构
1. **多分支特征提取**: 不同尺度的特征学习
2. **注意力机制**: 多头自注意力和交叉注意力
3. **几何约束网络**: 物理启发的约束层
4. **多头预测**: 集成多个预测头的结果
5. **不确定性估计**: 预测置信度量化

### 训练策略
1. **数据增强**: 坐标扰动和噪声注入
2. **高级损失函数**: Huber损失 + 几何一致性损失
3. **学习率调度**: 余弦退火重启
4. **混合精度训练**: GPU内存优化
5. **早停机制**: 防止过拟合

### 评估方法
1. **RMSE计算**: 使用Kabsch算法刚性对齐
2. **成功率统计**: RMSE ≤ 0.5Å 的比例
3. **官方评分**: 按照竞赛标准计算分数
