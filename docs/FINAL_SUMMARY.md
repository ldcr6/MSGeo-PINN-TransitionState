## 📊 评分计算

### 官方评分公式

**RMSD评分（40分）**:
```
IF RMSD ≤ 0.2:  40分
IF 0.2 < RMSD < 0.5:  40 - ((RMSD - 0.2) / 0.3) × 40
IF RMSD ≥ 0.5:  0分
```

**成功率评分（30分）**:
```
分数 = (成功数 / 500) × 30
其中成功 = RMSD ≤ 0.5Å
```

### 性能预期

基于优化策略，预期：
- **数据量提升** → RMSD降低40-50%
- **模型容量增加** → RMSD额外降低10-15%  
- **训练优化** → RMSD额外降低5-10%

**综合预期**: 0.483 × 0.4 ≈ **0.19-0.24 Å**
